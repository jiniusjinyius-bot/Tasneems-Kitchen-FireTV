# Tasneem's Kitchen - Fire TV 🍛

Smart Recipe App for Amazon Fire TV | Amazon Alexa Hackathon 2026

Built by Tasneem from Nagpur - Home Chef turned App Developer

### 🔥 Features
- 11 Authentic Indian Recipes (Biryani, Haleem, Kabab, Nihari etc.)
- Alexa Voice Control - "Alexa, open Tasneem's Kitchen"
- 4K Optimized UI for Fire TV Stick
- In-App Recipe Book (Payhip Integration)

### 🛠️ Built With
- Niotron / MIT App Inventor
- Alexa Voice Service
- Amazon Fire TV OS

### 🎯 Why Fire TV?
Indian cooking needs hands-free help! With Fire TV + Alexa, users can cook while watching recipes on big screen.
